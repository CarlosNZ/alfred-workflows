Scratch'n'Stick: a new sticky note's size, test cases

How to test: select the text between a case's >>> and <<< lines (not the markers) and run the Universal Action "New sticky note"; or copy it and use `newsticky` → "New sticky note from clipboard". Close each test note afterwards (⌘⌫ moves it to the Trash).

Sizes are the window on screen in points, width × height, predicted for this Mac's main screen (visible area 3440 × 1410) with the default 14 pt font. The caps there are 800 wide and 987 tall. On a smaller screen the caps are lower (on a 1440 × 875 laptop, 576 × 612), so the big cases come out smaller. Every note is at least the usual 360 × 288.

If a font_size other than 14 is set in the workflow's Configuration, every size scales with it.
