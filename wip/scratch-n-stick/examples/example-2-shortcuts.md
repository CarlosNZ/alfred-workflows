# Keyboard shortcuts

Keep this one on the desktop until your fingers know them.

| In the results list |                         |
| ------------------- | ----------------------- |
| ↩                   | Open a note in Alfred   |
| ⌘↩                  | Stick it to the desktop |
| ⌥↩                  | Move it to the Trash    |
| ⌃↩                  | Show it in Finder       |

In the results list, ⌘↩ on a sticky note closes it instead, and on a closed one (📌💤) unsticks it.

| In a note |                         |
| --------- | ----------------------- |
| ↩ and ⌘↩  | Edit and Preview        |
| ⌘1 to ⌘6  | Colour                  |
| ⌘+ ⌘− ⌘0  | Font size               |
| ⌘K        | All the actions         |
| ⌘D        | Stick to the desktop    |
| ⌘W        | Close a sticky note     |
| ⇧⌘W       | Close it and unstick it |
| ⌘⌫        | Move to the Trash       |

`scratch` lists your notes and `sticky` your sticky notes; `newscratch` and `newsticky` start new ones.
