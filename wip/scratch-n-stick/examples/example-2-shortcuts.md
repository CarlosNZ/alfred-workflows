# Keyboard shortcuts

You might want to keep this stuck to your desktop for a bit. The keys in a note are the usual Mac ones.

## In Alfred's `scratch` results

| Key | Action                  |
| --- | ----------------------- |
| ↩   | Open a note in Alfred   |
| ⌘↩  | Stick it to the desktop |
| ⌥↩  | Move it to the Trash    |
| ⌃↩  | Show it in Finder       |

⌘↩ on a *sticky* note closes it instead, and on a closed one (📌💤) unsticks it.

## In a note

| Key        | Action                  |
| ---------- | ----------------------- |
| ↩          | Edit                    |
| ⌘↩         | Preview                 |
| ⌘1 to ⌘6   | Colour                  |
| ⌘+, ⌘−, ⌘0 | Font size               |
| ⌘K         | Open the "Actions" menu |
| ⌘D         | Stick to the desktop    |
| ⌘W         | Close a sticky note     |
| ⇧⌘W        | Close it and unstick it |
| ⌘⌫         | Move to the Trash       |

## Alfred keywords

| Keyword      | Action                  |
| ------------ | ----------------------- |
| `scratch`    | List your notes         |
| `sticky`     | List your sticky notes  |
| `newscratch` | Start a new note        |
| `newsticky`  | Start a new sticky note |

You can change these in the workflow's configuration.
